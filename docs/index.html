Install once

Clone the repository and run the zero-dependency verification suite from your terminal, or install directly into Claude Code, OpenAI Codex, Gemini CLI, and Google Antigravity.

git clone https://github.com/jangtrinh/design-os-vietnamese
cd design-os-vietnamese
python3 -m unittest discover -s tests -v
python3 scripts/self_check.py && python3 tools/verify_ukmc.py

First safe use

  1. List all active universal and domain rule codes across the linter engine. 
    python3 shared/scripts/validate_copy.py --list-rules
  2. Run a read-only JSON audit on a Vietnamese file with domain and audience register enforcement. 
    python3 shared/scripts/validate_copy.py README.vi.md --domain edu --register edu-postgrad --json
  3. Write NFC-normalized and tone-standardized output to a separate clean file without mutating the source in place. 
    python3 shared/scripts/validate_copy.py README.vi.md --fix-tone new --output /tmp/readme.clean.md

A practical loop

validate_copy.py

Lints UTF-8 NFC normalization, mojibake, English calques, syntactic translationese, superlatives, diacritics, tone marks, numbers, ICU plurals, 31 registers, and 109 domain rules.

check_i18n_parity.py

Compares en.json and vi.json catalogs for missing keys, placeholder parity, NFD corruption, ICU other-only plural compliance, and UI expansion character caps.

check_font_coverage.py

Audits CSS font stacks and @font-face unicode-range declarations for complete 134 precomposed Vietnamese glyph coverage across Latin Extended-A/B and Latin Extended Additional.

verify_ukmc.py

Verifies all 18 UKMC.v1 knowledge modules, 65+ inline ease:source SHA-256 anchors, and the STOP_SUFFICIENT epistemic gate.

Frequently asked questions

What is DESIGN:OS Vietnamese?

DESIGN:OS Vietnamese is a sovereign, zero-dependency Vietnamese (vi-VN) language, typography, UX design system, 7-tier pedagogy (Preschool to Doctoral and GS/PGS), and 16-domain statutory compliance suite for AI coding agents. It ships 16 production skills, 31 audience registers, 131 deterministic AST/regex rules, 489 golden evaluation pairs, and 18 UKMC.v1 cryptographically verified knowledge modules.

How is DESIGN:OS Vietnamese installed?

Install via Claude Code plugin marketplace (/plugin marketplace add jangtrinh/design-os-vietnamese), or clone the repository and copy skills/* into ~/.claude/skills/, ~/.codex/skills/, ~/.gemini/config/skills/, or ~/.agents/skills/.

How does it cover the 7-tier Vietnamese pedagogy continuum?

The vietnamese-education-copy skill enforces statutory terminology and grading rules across all 7 educational tiers: Tier 1 Preschool (Nhà trẻ 3–36 months and Mẫu giáo 3–6 years under VBHN 01/VBHN-BGDĐT with qualitative-only assessment), Tier 2 Primary (Circular 27/2020/TT-BGDĐT), Tier 3 Secondary and High School (Circular 22/2021/TT-BGDĐT), Tier 4 TVET (Circular 04/2022/TT-BLĐTBXH), Tier 5 Undergraduate VQF Level 6 (Circular 08/2021/TT-BGDĐT), Tier 6 Master's VQF Level 7 (Circular 23/2021/TT-BGDĐT), and Tier 7 Doctoral VQF Level 8 plus GS/PGS Academic Ranks (Circular 18/2021/TT-BGDĐT and Decision 37/2018/QĐ-TTg).

Does DESIGN:OS Vietnamese send telemetry or require external pip packages?

No. Every linter (validate_copy.py, check_i18n_parity.py, check_font_coverage.py) and epistemic verifier (verify_ukmc.py, self_check.py) runs 100% offline using the Python 3.9+ standard library with zero external dependencies and zero telemetry.
